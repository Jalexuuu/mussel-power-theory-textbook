# Chapter 1: What is steno

## Steno is stroked
Steno utilises "strokes", rather than sequential presses

With Qwerty, you would press `R` then `A` then `T`. 

`R/A/T` -> rat

With steno you press `initial R` + `A` + `final T` simultaneously. 

`RAT` -> rat

## Steno is made up of chords

You may have noticed many sounds are missing. They're not actually missing, instead, they're "hidden" behind chords.

There is no dedicated `I` key, but that's fine, we simply use `EU`

| steno | translation |
|--|--|
| `KEUT` | `kit` |
| `SP/LEUT` | `split` |


## Steno is phonetic

You can largely ignore spelling if you know the sound

| `AEU` | `long A` |
|------|------|
| `WAEU` | `way` |
| `TRAEUN` | `train` |
| `FRAEUT` | `freight` |
| `S/NAEUK` | `snake` |


## Steno is spelling-based

To avoid homophones, some rules pay attention to spelling


| `AEU` -> `long a`  | `AE` -> `ea` |
|------|------|
| `BRAEUK` -> `brake` | `BRAEK` -> `break` |

.
| `AOU` -> `long u` | `AO` -> `oo` |
|------|------|
| `LAOUT` -> `lute` | `LAOT` -> `loot` |

.
|  | `-G` -> `gh` |
|------|------|
| `AEUT` -> `ate` | `AEUG/T` -> `eight` |
